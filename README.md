# Задачи для frontend-интервью

React, TypeScript, Vite и lodash. Десять независимых задач на junior++ / middle frontend.

## Запуск

Нужны Node.js 22.12+ и Yarn Classic 1.22.22. Рекомендуемая версия Node.js указана в `.nvmrc`.

```sh
nvm use
yarn install --frozen-lockfile
```

| Команда | Файл | Тема |
| --- | --- | --- |
| `yarn a` | `a.ts` | Порядок логов: Promise и таймеры |
| `yarn b` | `b.ts` | Порядок логов: дождаться таймера |
| `yarn c` | `c.ts` | Палиндром |
| `yarn d` | `d.ts` | Свои map и filter с типами |
| `yarn e` | `e.ts` | infer, conditional и mapped types |
| `yarn f` | `f.ts` | Типизированный Emitter и get по пути |
| `yarn g` | `g.tsx` | React, инпут и сервер |
| `yarn h` | `h.ts` | Порядок сообщений |
| `yarn i` | `i.tsx` | Вёрстка: карточки тарифов |
| `yarn j` | `j.ts` | LRU-кэш на Map |

`yarn g` запускает Vite и открывает браузер. Основной файл для правок в этой задаче: `g.tsx`. Отрисовка сервера и стили лежат в `src/`. `yarn i` открывает `i.html`: правьте `i.tsx` и `i.css`.

Консольные файлы запускаются через `tsx`, без проверки типов. Задачи `d`, `e`, `f` проверяются командой `yarn typecheck:tasks`: в исходном состоянии она падает, это нормально. Задача решена, когда ошибок нет, включая неиспользованные `@ts-expect-error`. Эти три файла исключены из `yarn typecheck` и `yarn build`, чтобы сборка не зависела от решения. Заглушки `d` и `f` бросают «Не реализовано» при запуске.

В `b` и `h` вывод изначально идёт не по порядку, в `c` оставлена заглушка, в `j` часть строк таблицы показывает `✗`. Это исходное состояние заданий.

```sh
yarn typecheck        # a, b, c, g, h, i, j и src; d, e, f не входят
yarn typecheck:tasks  # d, e, f
yarn build
yarn preview
```

Материалы для интервьюера находятся в `INTERVIEWER.md`, включая решение React-задачи. Если кандидат не должен видеть ответы, уберите этот файл из выдаваемой ему версии репозитория. В общей истории Git файл останется доступным.
