# Задачи для frontend-интервью

React, TypeScript, Vite и lodash. Восемь независимых задач на junior++ / middle frontend.

## Запуск

Нужны Node.js 22.12+ и Yarn Classic 1.22.22. Рекомендуемая версия Node.js указана в `.nvmrc`.

```sh
nvm use
yarn install --frozen-lockfile
```

| Команда | Файл | Тема |
| --- | --- | --- |
| `yarn a` | `a.ts` | Порядок логов: Promise и таймеры |
| `yarn b` | `b.ts` | Порядок логов: async/await |
| `yarn c` | `c.ts` | Палиндром |
| `yarn d` | `d.ts` | Тип аргумента и результата |
| `yarn e` | `e.ts` | Типизация доступа к свойству |
| `yarn f` | `f.ts` | Типизация map |
| `yarn g` | `g.tsx` | React, инпут и сервер |
| `yarn h` | `h.ts` | Порядок сообщений |

`yarn g` запускает Vite и открывает браузер. Основной файл для правок в этой задаче: `g.tsx`. Отрисовка сервера и стили лежат в `src/`.

Консольные файлы запускаются через `tsx`, без проверки типов. В задачах `d`, `e`, `f` проверяйте типы в редакторе и командой `yarn typecheck`. Исходные `any` намеренные: успешный запуск ещё не означает, что типизация решена.

В `c` оставлена заглушка, а в `h` сообщения изначально выводятся в неверном порядке. Это исходное состояние заданий.

```sh
yarn typecheck
yarn build
yarn preview
```

Материалы для интервьюера находятся в `INTERVIEWER.md`, включая решение React-задачи. Если кандидат не должен видеть ответы, уберите этот файл из выдаваемой ему версии репозитория. В общей истории Git файл останется доступным.
